# Исправления повторного аудита — MintVault 1.1.8

28 октября 2026 года.

| Замечание | Изменение | Регрессия |
| --- | --- | --- |
| CLI backup заблокирован | Интерактивный пароль / `--recovery`, unlock, context manager | Пароль, recovery, неверный пароль, проверка копии |
| Приватные каталоги становились 0755 | Новые каталоги всегда 0700 | Извлечение при umask 000 |
| Неверный путь деинсталлятора | Manifest установки, идентичность каталога и файлов, SHA-256 | Отказ без manifest, dry-run, сохранение неизвестных и изменённых файлов |
| Ошибки fsync скрывались | Ошибки передаются вызывающему коду, после публикации сбрасывается состояние | EIO, повторная разблокировка и проверка |
| Header-only объявлял полную целостность | Отдельное сообщение о структурной проверке | Повреждённый шифротекст и header-only |
| Повреждённые блоки переносились | Полная криптографическая проверка временного контейнера | Отказ обновления без изменения исходных байтов |
| Файл мог быть родителем | Валидация дерева при добавлении и разборе индекса | Отказ добавления без изменения контейнера |
| Backup GUI игнорировал отмену | Callback отмены и прогресса передаётся в API | Отмена при копировании и проверке, очистка временных файлов |

Дополнительно: обновление установки сохраняет неизвестные файлы внутри пакета; версия в метаданных и приложении — 1.1.8.

Проверено: `python3 -m unittest discover -s tests -q` — 39 тестов, 37 пройдены, 2 пропущены. Пропуски: отсутствует эталон старого контейнера, отсутствует дисплей/Xvfb для запуска GTK-окна. GTK импортируется, интеграционные тесты установки/удаления и CLI проходят. `compileall`, `bash -n` и `doctor` проходят.

Полная ручная проверка GUI на Linux Mint не выполнена. CI Ubuntu с GTK/Xvfb добавлен, но удалённый запуск CI в этой работе не выполнялся. Исправления и регрессии не являются доказательством отсутствия других дефектов. Исходные архивы сохранены.
